How to read the graph

Dots and lines
Each dot is one board position and each line is a move. Rotations and mirror images count as the same position, which shrinks the 5,478 reachable boards to 765 dots. The top dot is the empty board and the bottom rows are finished games.
Colour of a dot
The result from that position if both players play perfectly: blue means X wins, grey a draw, red O wins. The empty board is grey because perfect play always ends in a draw.
Faint dots
Positions the current search has not reached. Before each computer move every dot is faint, and only the dots below the current position can light up.
The search wave
Minimax plays every continuation out to the end, then passes each result back up to the position before it. Dots light up in the order minimax finishes them: finished games first, then their parents, until it reaches the current position.
Scores on the lines
The lines leaving the ring are the computer's options, labelled with its score. A win scores 10 minus the number of moves it takes, so faster wins score higher. A loss scores the moves minus 10, and a draw scores 0. The thick green line is the move it plays, picked at random among equal scores.
White line and ring
The white line traces the game so far and the ring marks the current position. Hover or tap any dot to see its board and what perfect play gives from there.
